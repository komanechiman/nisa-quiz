# とうしクイズ 110

2027年1月に始まる**こどもNISA**と、投資信託・つみたての基礎を 4 択で学ぶ、小中学生向けクイズアプリ。
全 11 ジャンル × 10 問 = 110 問。まちがえるとその場で解説が出ます。

`eki-quiz` と同じく、ビルド不要の静的サイト（HTML + JS のみ）です。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体（UI・CSS・ロジック） |
| `questions.js` | 問題データ 110 問（`window.QUIZ_DATA`） |
| `config.js` | アプリ名とメール送信先の既定値（ふつうは空のまま） |
| `manifest.json` | PWA 用（ホーム画面に追加できる） |
| `apps-script/Code.gs` | 結果メールを送る Google Apps Script（任意・そのまま貼るだけ） |
| `apps-script/SETUP.md` | 上のセットアップ手順（画面ごとの説明） |

## ローカルで動かす

```
python -m http.server 8777
```

→ http://localhost:8777

（`file://` で直接開くと `questions.js` が読み込めないので、必ずサーバー経由で）

## 📧 結果メールを受け取る（任意）

1 セット終わるたびに「だれが・どのジャンルを・何点だったか・どこを間違えたか」がメールで届きます。

GitHub Pages は静的サイトなのでページ自身はメールを送れません。中継として **Google Apps Script**
を使います（無料・自分の Google アカウント内で完結・外部サービスを経由しない）。

### 手順

**→ 画面ごとの詳しい手順は [`apps-script/SETUP.md`](apps-script/SETUP.md) にあります。**
（権限の「このアプリは確認されていません」警告の通りかたも書いてあります。ここで詰まる人が多いので）

ざっくり言うと:

1. script.google.com で新しいプロジェクトを作り、`apps-script/Code.gs` を丸ごと貼る（**編集不要**）
2. 「デプロイ」→「ウェブアプリ」、アクセスできるユーザーを **全員** にして公開
3. 出てきた `.../exec` の URL を**ブラウザで開く**と、合言葉が表示される（初回のみ）
4. アプリの **⚙️ せってい** に URL と合言葉を貼って「保存」→「テスト送信」

合言葉はスクリプトが自動で発行します。見逃したらエディタで `showSecret` を実行すれば再表示できます。

送り先は、既定では **そのスクリプトを持っている Google アカウント宛** です
（`Session.getEffectiveUser()`）。別のアドレスに送りたいときだけ `Code.gs` の `TO` を書き換えてください。

### URL をどこに置くか

| 置き場所 | メリット | 注意 |
| --- | --- | --- |
| ⚙️ せってい（既定） | リポジトリに URL が残らない | 端末ごとに 1 回貼る必要がある |
| `config.js` | 全端末で設定不要 | **公開リポジトリだと URL と合言葉が誰でも見られる** |

**URL が第三者に知られると、その人はあなた宛にメールを送れてしまいます。**
公開リポジトリにする場合は `config.js` を空のままにし、`Code.gs` の `SECRET` を必ず設定してください。
`Code.gs` 側には合言葉の照合に加えて、1 時間あたりの送信上限（既定 30 通）も入れてあります。

### 挙動のメモ

- 送信は「プレイするたび毎回」。結果画面に「おうちの人に けっかを おくったよ ✉️」と表示されます（隠して送る作りにはしていません）
- 圏外・電源切れなどで送れなかった結果は端末内にたまり、次にプレイしたときや「保存」「テスト送信」のときにまとめて再送されます
- 再送と初回送信がすれ違って二重に届かないよう、結果ごとに `id` を振り、`Code.gs` 側で 6 時間以内の同一 `id` は捨てています
- 「せってい」でメールを OFF にすれば、通信は一切しません（アプリはオフラインでも動きます）

## なまえ（プレイヤー）

起動すると、まず **「だれが やる?」を 4 択**（あいり / さき / まま / ぱぱ）で聞きます。
選ぶまでジャンル一覧は出ません。選んだあとはメニュー上部の小さなボタンでいつでも切り替えられます。

**記録はなまえごとに完全に分かれます** — ベストスコア・プレイ回数・まちがい復習リストが混ざりません。
だれがやったかはメールの件名にも入ります。

名前を変えたい・人を増やしたいときは `config.js` の `PLAYERS` を書きかえてください。

```js
PLAYERS: ["あいり", "さき", "まま", "ぱぱ"],
```

（名前を変えると、その名前で貯めていた記録は参照されなくなります）

### 一人一台のとき：毎回えらばせない

端末が本人専用なら、**⚙️ せってい →「この端末は いつもこの人」にチェック**を入れると、
えらぶボタンが消えて「👤 あいり この端末」という小さな表示だけになります。

あわせて、**その人ぶんのリンク**（⚙️ でコピーできます）をホーム画面に追加しておくのが確実です。

```
https://komanechiman.github.io/nisa-quiz/?me=あいり
https://komanechiman.github.io/nisa-quiz/?me=さき
https://komanechiman.github.io/nisa-quiz/?me=まま
https://komanechiman.github.io/nisa-quiz/?me=ぱぱ
```

`?me=` つきで開くと、その人に切りかわって自動的に固定されます。

### ⚠️ iPhone / Safari の注意

Safari には **7 日間そのサイトを使わないと localStorage を消す**仕様（ITP）があります。
消えると、えらんだ名前・記録・まちがい復習リスト・メール設定がすべて初期化されます。

**ホーム画面に追加したウェブアプリはこの対象外**になるので、iPhone で使う人は
Safari で開く → 共有ボタン → **「ホーム画面に追加」** を必ずやってください。
上の `?me=` つきリンクから追加しておけば、万一消えても名前だけは復帰します。

Android の Chrome にはこの制限はありません。

## 問題を足す・直す

`questions.js` だけを編集すればOK。形式は：

```js
{
  q: "問題文",
  c: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  a: 0,              // 正解のインデックス（0〜3）
  e: "まちがえたときに出る解説"
}
```

選択肢の並び順は出題のたびにシャッフルされるので、`a` の位置は気にしなくて大丈夫です。
ジャンルを増やすときは、配列の要素として `{ id, name, emoji, color, desc, qs: [...] }` を追加します。
ジャンル数と問題数は画面に自動で出るので、増やしても文言を直す必要はありません
（`index.html` の `<title>` とヘッダーの数字だけは手動です）。

## 内容についての注意

### こどもNISA（`kodomo` ジャンル）の根拠

2026 年の法改正で成立、**2027 年 1 月 1 日開始**。正式名称は「未成年者特定累積投資勘定」。

| 項目 | 内容 |
| --- | --- |
| 対象年齢 | 0〜17 歳 |
| 年間投資枠 | 60 万円 |
| 非課税保有限度額 | 600 万円 |
| 非課税保有期間 | 無期限 |
| 対象商品 | つみたて投資枠の対象投資信託のみ／定時・定額（一括不可） |
| 払出し | 原則 12 歳以降。使途が子のためであること＋子本人の同意書面＋親権者等が申出書を金融機関に提出 |
| 18 歳到達時 | 手続き不要で成人のつみたて投資枠へ自動移行 |
| 生涯 1,800 万円との関係 | こどもNISAの 600 万円は 1,800 万円に**含まれる**（使い切ると残り 1,200 万円） |

一次資料：金融庁「アクセスFSA 2026年2月号」政策解説
<https://www.fsa.go.jp/access/r7/270/270_03.pdf>
／金融庁「令和8年度税制改正大綱における金融庁関係の主要項目について」
<https://www.fsa.go.jp/news/r7/sonota/20251226-2.html>

### その他

- 大人の NISA の数字（年 120／240 万円、生涯 1,800 万円）は 2024 年開始の新 NISA にもとづいています。
- ジュニアNISA は 2023 年末で新規投資が終了しています（`nisa` ジャンルで扱っています）。
- 同じ税制改正で、つみたて投資枠の指定指数に読売株価指数（読売333）と JPX プライム 150 指数が追加され、
  指定指数に連動しない投信の要件が「株式 50% 超」から「株式＋公社債で 50% 超」に緩和されました。
  子ども向けには細かすぎるため出題していません。必要なら `index` ジャンルに追加してください。
- 制度変更があったら `questions.js` の `nisa` / `kodomo` ジャンルと、`index.html` の `.notice` を更新してください。
- 特定の金融商品をすすめる内容は含めていません。
