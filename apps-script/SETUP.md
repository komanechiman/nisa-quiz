# 結果メールのセットアップ手順

パソコンで、通しで **5〜10分** です。コードは書きかえません。コピーして貼るだけです。

やることは3つだけ。

1. Google のサーバーに「送信係」を置く
2. 出てきた **URL** と **合言葉** をメモする
3. とうしクイズの ⚙️ に貼る

---

## なぜこれが必要か

とうしクイズは GitHub Pages に置いてあります。ここは「ファイルを置いておくだけ」の場所なので、
**ページ自身はメールを出せません**。

そこで、メールを出す係を別に用意します。それが Google Apps Script です。
自分の Google アカウントの中で動く小さなプログラムで、外部の会社は一切通りません。追加の登録も料金もなし。

```
子どものスマホ  ──→  あなたの Apps Script  ──→  あなたの Gmail
  （結果を送る）        （受け取って転送）          （届く）
```

---

## ステップ 1 ── プロジェクトを作る

1. パソコンのブラウザで **https://script.google.com/** を開く
   （いつも使っている Google アカウントでログインしておく）
2. 左上の **「＋ 新しいプロジェクト」** をクリック
3. エディタが開き、こう書かれた状態になっています

   ```js
   function myFunction() {
   }
   ```

4. **この3行を全部消します**（エディタの中をクリック → `Ctrl + A` → `Delete`）
5. このフォルダの **`Code.gs`** の中身を**全部**コピーして、貼りつけ
6. `Ctrl + S` で保存
7. 左上の「無題のプロジェクト」をクリックして、**「とうしクイズ」**など好きな名前に

---

## ステップ 2 ── 公開（デプロイ）する

1. 右上の青い **「デプロイ」** ボタン → **「新しいデプロイ」**
2. 左上の **歯車アイコン⚙** をクリック → **「ウェブアプリ」** を選ぶ
3. 設定をこうします

   | 項目 | 選ぶもの |
   | --- | --- |
   | 説明 | （空でOK） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** ← ここ超重要 |

   > 「全員」が怖く感じますが、合言葉を知らない人のリクエストは弾く作りにしてあります。
   > スマホからアクセスするには、この設定でないと届きません。

4. **「デプロイ」** をクリック

---

## ステップ 3 ── 権限を承認する（初回だけ・ここが一番つまずく）

初めてデプロイすると、権限を求められます。見慣れない警告が出ますが、
**自分で書いたプログラムを自分で許可するだけ**なので問題ありません。

1. **「アクセスを承認」** をクリック
2. Google アカウントを選ぶ
3. **「このアプリは Google で確認されていません」** という警告が出ます

   ここで多くの人が止まりますが、進めて大丈夫です。

   - 左下の **「詳細」**（または「Advanced」）をクリック
   - 下に出てくる **「とうしクイズ（安全ではないページ）に移動」** をクリック

4. 「Gmail の……メールを送信」などの権限一覧が出たら **「許可」**

> この警告は「Google の審査を受けていない個人のスクリプト」に必ず出るものです。
> 審査は一般公開アプリ向けのもので、自分専用のスクリプトには不要です。

---

## ステップ 4 ── URL と合言葉を受け取る

1. デプロイ完了の画面に **「ウェブアプリ」の URL** が出ます

   ```
   https://script.google.com/macros/s/AKfycb.................../exec
   ```

   **これをコピー**（末尾が `/exec` であることを確認）

2. その URL を**そのままブラウザのアドレス欄に貼って開きます**
3. 「✅ 受信サーバーは動いています」というページが出て、**合言葉**が表示されます

   ```
   ✅ 受信サーバーは動いています

   この「合言葉」をアプリの ⚙️ に貼ってください。

        ┌────────────────────┐
        │     k7m2pqx4rt     │
        └────────────────────┘

   ⚠️ この合言葉が表示されるのは、この1回だけです。
   ```

   **合言葉をメモしてください。**

   > 見逃しても大丈夫です。Apps Script のエディタに戻り、上部の関数リストから
   > **`showSecret`** を選んで「▶ 実行」を押すと、下の「実行ログ」に出ます。

---

## ステップ 5 ── アプリに貼る

1. スマホ（またはパソコン）で https://komanechiman.github.io/nisa-quiz/ を開く
2. **⚙️** をタップ
3. 「けっかをメールで送る」のところに

   - **受信URL** … ステップ4の `.../exec`
   - **あいことば** … ステップ4の合言葉

4. **「メールを送る」にチェック** を入れて **「保存」**
5. **「テスト送信」** を押す

   → 「受信サーバーに届きました」と出て、あなたの Gmail にテストメールが来れば完成です。

これ以降、そのスマホで1セット終わるたびに結果が届きます。

> ⚠️ URL と合言葉は**スマホごとに**入れる必要があります（端末の中にだけ保存されるため）。
> あいり・さき・まま・ぱぱ、それぞれの端末で一度ずつ同じ作業をしてください。

---

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| テスト送信で「受信サーバーに届きませんでした」 | URL が `/exec` で終わっているか確認（`/dev` は不可）。デプロイの「アクセスできるユーザー」が **全員** になっているか確認 |
| 「届きました」と出るのにメールが来ない | 合言葉が違う可能性。`showSecret` で確認して入れなおす。迷惑メールフォルダも確認 |
| URL をブラウザで開くとエラー画面 | 権限の承認（ステップ3）が終わっていない。デプロイし直して承認する |
| 途中で URL を見失った | Apps Script の「デプロイ」→「デプロイを管理」で確認できます |
| 合言葉を作りなおしたい | エディタで関数 **`resetSecret`** を実行 → 実行ログに新しい合言葉。アプリ側も入れなおす |
| メールがまったく送られていないか確認したい | エディタで関数 **`sendTestMail`** を実行すると、スマホを使わずに1通送れます |

## コードを直したあと

「デプロイ」→ **「デプロイを管理」** → 鉛筆アイコン → バージョンを **「新バージョン」** → 「デプロイ」。
URL は変わりません。

（「新しいデプロイ」を押すと**別の URL** ができてしまい、アプリ側の貼りなおしが必要になります）

## 使われる権限について

このスクリプトが求める権限は **メールを送る権限だけ**です。
メールを読んだり、他のファイルを触ったりはしません。`Code.gs` を読めば、
`MailApp.sendEmail` 以外に外へ出ていく処理がないことが確認できます。

1日に送れるメールの数は、無料の Google アカウントで **100通** までです（このアプリの使い方なら十分）。
スクリプト側でも、いたずら対策として1時間30通の上限を入れてあります。
